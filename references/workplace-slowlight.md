# 职场冷知识与慢拾光承接

仅在用户要求职场、成长、注意力、信息判断、慢拾光或产品承接时读取本文件。

## 内容边界

优先选择能被权威来源核实、能用一个画面表达、能转化成一次低风险练习的主题：

- 职场认知：注意力切换、信息过载、沉没成本、决策偏差。
- 工作表达：确认需求、进度汇报、区分事实与评价、会议信息提炼。
- 信息判断：图表误导、来源核验、相关与因果、数字口径。
- 职场安全：钓鱼邮件、假冒领导、密码与隐私、紧迫感操纵。

首轮避免：个案劳动法结论、心理疾病诊断、医疗建议、未经验证的“管理学定律”、对群体或人格类型的刻板判断、保证升职或收入的承诺。

## 卷卷与小糯的角色分工

- 卷卷负责发现异常、提出问题、进行验证和制造短视频记忆点。
- 小糯负责在慢拾光中陪练、记录真实训练时间、心得和成长进度。
- 联动表达固定为：`卷卷发现，小糯陪你练会。`
- 不把两个角色合并，也不改变卷卷或小糯已有外形。

## 职场短片结构

每期只解决一个具体问题：

1. **异常场景**：2 秒内出现办公桌、聊天窗口、会议、图表或通勤等清晰情境。
2. **本能误判**：卷卷采取常见但不理想的反应，笑点来自情境而非羞辱人物。
3. **准确原则**：用一句窄而准确的口播解释，不堆概念。
4. **现实动作**：给观众一个第二天能尝试的小动作。
5. **反差退场**：让消息气泡、文件、错误图表或场景机关自然带走卷卷。
6. **空镜承接**：后期添加训练卡名称和联动语，不让生成模型直接做文字。

## 慢拾光训练卡映射

默认先映射到现有“生活通识”主题，标题可使用 `职场微训练｜{主题}`。只有在用户确认独立栏目并准备修改应用结构时，才建议新增顶级主题。

每条视频对应一张训练卡，输出以下字段：

```yaml
episode_id: "JJ-WK-001"
series: "卷卷职场冷知识"
video_title: ""
verified_fact: ""
source_name: ""
source_url: ""
confidence: "高/中，并说明限制"
slowlight_theme: "生活通识"
slowlight_card_title: "职场微训练｜"
estimated_minutes: 7
goal: ""
setup: ""
task: ""
content: "约 300–600 字，说明情境、原理、边界和现实动作"
steps:
  - "识别情境"
  - "作出判断"
  - "完成一次现实微练习"
questions:
  - prompt: ""
    options: ["", "", "", ""]
    answer: 0
    explanation: ""
reflection_question: ""
campaign_id: "JJ-WK-001"
source_channel: "待发布时填写"
end_card_copy: "慢拾光｜今日 7 分钟训练：{短标题}"
```

默认提供 3 道题：一题检查事实、一题判断具体场景、一题选择现实动作。错误选项应像真实误判，不能明显荒谬；解释需要说明为什么，而不只重复正确答案。

## 快速验证模式

用户要求商业化、引流或验证时，除视频与训练卡外再输出：

- 一个合规的片尾 CTA；
- `episode_id/campaign_id/source_channel`；
- 需要观察的四项数据：视频主页访问或链接点击、训练开始、训练完成、次日再次训练；
- 若测试付费，明确标注概念演示或预售范围，不虚构用户评价、成交量或合作案例。

首轮优先用 3–7 条内容验证，不因测试而先开发完整会员、支付或第五个顶级栏目。
