# 封面、片尾与发布文案

## 封面

- 默认各生成一张 4:3 横版与 3:4 竖版；需要平台专版时再适配 16:9 或 9:16。
- 普通内容标题使用 `卷卷冷知识`；职场内容使用 `卷卷职场冷知识`。
- 大号圆润中文字体，暖白至浅黄色填充、深靛蓝描边、轻微珊瑚橙阴影。
- 卷卷、本期核心主体和现象占据主要视觉区域；一眼看出“谁、发生了什么”。
- 两种比例必须重新构图，不得用简单裁切代替。
- 无英文、虚假背书、水印、额外角色或难以辨认的小元素。

## 片尾承接

慢拾光联动时，在“卷卷还会回来的——”后的干净空镜中由后期添加一条简短文字：

```text
慢拾光｜今日 7 分钟训练：{训练卡短标题}
卷卷发现，小糯陪你练会
```

不要让生成模型直接绘制文字、二维码、Logo 或应用界面。需要链接时使用平台允许的主页、组件或店铺能力，不使用规避平台规则的导流话术。

## 普通冷知识发布文案

默认使用：`可爱标题 → 准确冷知识 → 卷卷遭遇的笑点`，随后放 4–6 个相关话题。

```text
卷卷冷知识｜{形容词}的{本期主体}来啦！{emoji}

别看{表面印象}，其实{准确且简洁的事实解释}！

{本期现象或主体触发卷卷退场的笑点}～卷卷还会回来的！

#卷卷冷知识 #{主体} #{领域} #AI动画
```

## 职场冷知识发布文案

默认使用：`场景问题 → 窄而准确的结论 → 明天可执行的一个动作 → 慢拾光承接`。

```text
卷卷职场冷知识｜{一句具体场景问题} {emoji}

{经过核实、带必要条件的事实或原则。}

明天可以先试一件事：{单一、低风险、可执行动作}。

对应的 7 分钟理解训练：{慢拾光训练卡短标题}。
卷卷发现，小糯陪你练会。

#卷卷职场冷知识 #{具体主题} #职场成长 #慢拾光 #AI动画
```

不要使用“人人都适用”“立刻升职”“保证有效”等承诺，不把尚有条件限制的事实写成绝对结论。标签优先选择系列品牌、具体主题和内容领域，不堆无关热词；职场内容默认不使用 `#带娃` 等低幼标签。
