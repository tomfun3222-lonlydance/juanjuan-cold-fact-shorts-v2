# 卷卷可读故事大纲规范

用于用户选中主题后的剧情拓展、写剧本、大纲和完整剧集交付。纯选题、事实问答、封面或发布文案任务不强制附加故事大纲。

## 展示顺序

先在回复正文展示故事，再给核查说明、分镜和生成提示词。每次生成或修改大纲都必须同时保存为独立 Markdown 文件，也要让用户直接在回复中读到完整大纲；不能只给文件链接或压缩成时间表。完整制作包中的五段大纲单独保存，和制作包互相链接。

标题使用 `《卷卷冷知识：{主题标题}》`，依次列出类型、时长建议和基调；正文采用下面的五段结构。模板中的花括号是写作提示，交付时全部替换为实际内容。

```markdown
# 《卷卷冷知识：{主题标题}》

**类型**：可爱 3D 卡通 / {知识领域} / 轻喜剧
**时长建议**：{8–25} 秒
**基调**：{好奇} × {核心反差} × {原因揭晓} × {轻快收尾}

【序幕】
【{具体场所} · {日/夜}】
{用一小段写清光线、环境和本期完整主体的真实外形；让场景马上进入故事，卷卷仍在前 2 秒可辨认。}

【第一幕】
{卷卷如何出现、站在哪里，如何发现异常或提出猜想；交代关键主体与道具数量。}

卷卷说：
“{逐字开场或提问台词}”

{一个看得见的观察或验证动作，以及卷卷的具体反应。}

【第二幕】
{承接上一幕的同一个主体，按时间顺序发生关键现象；需要时明确左右方向、接触先后或条件。}

{简洁音效与卷卷的反应，让笑点有停顿。}

“{本幕确有需要的逐字对白；没有对白就删除这一行。}”

【第三幕】
{在现象发生后的稳定状态揭晓原因；原主体状态持续，不无故复原、复制或改变形态。}

卷卷说：
“{一句准确、易懂、保留必要条件的核心知识。}”

{本期主体或现象自然带来收尾动作，明确卷卷离场方向。}

卷卷说：
“卷卷还会回来的——”

【尾镜】
{卷卷离场后，镜头停在哪个明确场景和主体状态；通常保持约 1 秒清晰、安静的空镜。}
```

## 内容与节奏

- 五段各有任务：序幕交代场景；第一幕进场、发现或猜想；第二幕发生现象和反差；第三幕解释并退场；尾镜保留现象后的稳定画面。按主题灵活安排，不机械重复用户示例中的植物、昆虫、雨滴或台词。
- 用自然连贯的场景动作写大纲，把角色姿势、视线、反应与关键对白讲清楚。大纲中不塞资源编号、完整提示词、负面词串或分镜表。
- 五段不是五个镜头。8–12 秒可压缩在一个主动作中，13–18 秒可用一至两个镜头，19–25 秒通常两至三个镜头；在制作包中再给实际时间表。
- 为台词、吹气或其他不能同时说话的动作、喜剧反应和尾镜分别留时间。台词过长时先精简，不只修改总时长标签，也不靠过快配音塞满。
- 核心事实在写剧本前核查。用户给的示例先作为格式参考，不能把其中未经本次核实的科学说法直接当作事实模板。
- 同一个主体的数量、形态、空间方向和关键状态要前后连续。例如发生闭合、破裂或离场后，下一幕不能无解释地恢复初始状态。
- 用现象解释反差，喜剧动作不伪装成证据；不为照搬退场方式添加会扭曲本期原理的物理效果。
- 开场默认“卷卷来咯！”，收尾默认“卷卷还会回来的——”。用户明确指定本集台词时优先保留；单个格式示例中的问候不自动替换整个系列的默认台词。

## 大纲之后的核查说明与制作衔接

大纲后简要列出核实后的核心事实、可点击直接来源、发布日期或访问日期、置信度与必要适用条件。不要把长引用塞进角色口播。

需要完整制作包时，大纲是分镜和提示词的剧情依据；对白逐字一致，动作先后、主体数量、事实口径、屏幕方向、总时长及尾镜停留一致。核实后确需改台词或动作时，同时更新大纲和各个制作版本，不能只改提示词。

## 每次保存与版本命名

- 自动保存适用于每次新写或改写的剧本，包括仅大纲、候选稿、精简版和完整剧集；不以用户说“导出”“保存”或批准内容为前提。
- 用户指定存放位置时遵从用户；否则沿用本集已有项目目录，新主题默认使用当前工作区下的 `episodes/{YYYY-MM-DD}_{主题}/`。日期采用用户所在时区。
- 默认使用 UTF-8 Markdown，文件名为 `{主题}-对照剧本-v1.md`；先查看已有版本，改稿递增为 `v2`、`v3`，保留旧文件。仅重复展示已有版本时可复用原文件，不必制造内容相同的新版本。
- 文件必须包含标题、类型、时长建议、基调、完整五段剧情和逐字对白；不得只保存摘要或提示词。事实来源与必要制作备注可以放在剧情之后。
- 同次交付制作包时，使用相同版本号的 `{主题}-制作包-vN.md`，两份文件互相链接并保持对白、动作和时长一致。
- 回复前实际写入并回读确认内容完整，随后在回复中附上可点击的绝对路径文件链接；不要以文件链接代替正文剧本。保存失败时明确说明，不得声称已落盘。
