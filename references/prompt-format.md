# 卷卷首尾帧与图生视频提示词规范

## 首帧或尾帧文生图提示词

每张图都直接写明：

1. `竖屏 9:16，优质可爱哑光软胶 3D 卡通渲染`。
2. 卷卷完整固定身份和本集服装。
3. 场景空间、道具数量与尺寸、主体外形和真实特征。
4. 人物和主体的屏幕位置、朝向、姿势、视线与表情。
5. 景别、机位、镜头感、光线、色彩与稳定构图。
6. 尾帧必须是动作完成后的清晰停姿，不能运动模糊。
7. 负面约束：无文字、水印、额外角色、额外道具、额外肢体、身份漂移、五官或手指变形。

职场场景要让成年观众一眼识别，例如办公桌、会议室、通勤、电梯、电脑窗口、工牌或文件；不要依赖婴儿房、玩具教室等低幼环境。服装可以更换为衬衫、针织背心、工牌或通勤外套，但固定身体与验证环不得被遮挡或改变。

## 首尾帧图生视频提示词模板

```text
竖屏 9:16，优质可爱 3D 卡通短片，生成{时长}秒短视频。

1. 无切镜，严格根据首帧和尾帧参考图生成；严禁改变卷卷外观、服装、道具数量、主体形态、场景布局、光线和色彩。镜头{固定/轻微跟随}，{机位描述}。
2. 0–{时间}秒：{从首帧开始的单一主动作；明确屏幕左右、路径、速度、视线、表情和道具数量}。卷卷用{声音设定}说：“{台词}”。
3. {时间}–{时间}秒：{主体动作、卷卷观察或验证、必要音效}。
4. {时间}–{时长}秒：{结尾动作}。卷卷用同一声音说：“卷卷还会回来的——”。最后稳定定格为尾帧构图，至少停留 0.5 秒。

卷卷固定形象：薄荷绿色大椭圆头、右上额头深靛蓝立体顺时针螺旋、左方眼右圆眼、小短横嘴、两侧黄色腮红点、约 2.5 头身的小身体、左手腕珊瑚红空心验证环；哑光软胶质感的优质 3D 卡通角色，表演冷静、可爱、略带呆萌。{完整本集服装、环境、主体和光线描述}。

不要：切镜、转场、人物换脸、五官或螺旋变形、服装变化、额外肢体、额外道具、额外角色、文字、字幕、标志、二维码、水印、恐怖表情、突然变焦、镜头抖动、运动模糊、低清晰度。
```

声音设定默认：普通冷知识可使用可爱、乖巧的中文卡通声；职场内容使用清亮、年轻、略带呆萌但不幼儿化的中文中性卡通声。整条视频必须保持同一声线，不模仿真人。

## 25 秒分镜建议

- 镜头 1（4–7 秒）：有识别度的进场与“卷卷来咯”。
- 镜头 2（6–10 秒）：发现并观察现象，提出问题或演示误判。
- 镜头 3（6–10 秒）：事实揭晓、给出一个动作、现象触发退场和空镜。

总时长以各镜头之和计算，不能只修改标签。每镜分别生成一对首尾帧，不要求单个模型一次完成 25 秒复杂连续动作。

## LIBTV 静态分镜提示词顺序

1. 景别和机位。
2. `@场景资源名` 与空间结构。
3. `@角色资源名` 与物理尺寸锚点。
4. `@道具资源名`、数量、尺寸、材质和连接方式。
5. 角色姿势、视线、表情和屏幕位置。
6. 主体动作与物理交互。
7. 光线、配色、氛围和统一风格。

仅在资源确实存在时使用 `@资源名`。多视图参考图只锁定身份，不得复制成多个角色。

## LIBTV 视频运动提示词顺序

```text
画幅、总时长、无切镜与参考图锁定

出场角色：
@角色名，尺寸；完整固定身份与本集服装

背景场景与道具：
@场景名，空间尺度与关键结构
@道具名，数量、尺寸、材质

参考图使用规则：
- 角色参考图只锁定身份，不锁定角度、姿势、构图；多视图不得产生多人。
- 场景参考图锁定空间结构和比例，不产生镜像或复制。
- 道具参考图锁定结构、尺寸与正反面逻辑，不锁定位置。

前一个分镜描述：
{上一镜稳定尾帧状态；首镜写“当前分镜为故事开篇”}

当前分镜的分段描述：
0–X秒：
画面：{单一主动作、精确对白和反应}
禁止：{本段最可能发生的形变、穿模、重复或方向错误}
约束：{必须稳定实现的结果}
站位与朝向：{左右、前后、视线和路径}
运镜：{单一平滑镜头动作}
音效：{与动作同步的环境声或喜剧音效}

X–Y秒：
{按同一结构继续}

输出约束：
1. 卷卷身份和本集服装不可改变。
2. 主体的真实形态和动作不可被笑点扭曲。
3. 道具数量、比例、交互以及透明或反射材质必须稳定。
4. 首尾帧直接对应，尾帧清晰稳定，无运动模糊。
5. 无额外角色、文字、字幕、标志、二维码或水印。
```
